# Typing Hero

Typing Hero is a simple typing game where words fall from the top and you have to type them before they reach the red line......

I made this as a small typing challenge. 
The game gets faster when you keep typing words correctly.

## How to Play

Press Enter to start the game.

Words will start falling from the top...

Type the full word using your keyboard...

If you type the word correctly, 
it disappears and your score increases.

If a word reaches the*Miss Line.....you lose one life.

You have **3 lives** in every game.

When all 3 lives are gone...the game ends.

Press Enter again to restart.

## Features

- Falling words from direct heaven
- 3 lives you get
- Streak system according to ur perfomance
- WPM counter according to ur speed
- Game gets faster after every 5 word streak....
- Bonus score for streaks...
- Correct letters are shown in green
- Game over screen
- Restart using Enter


## Controls

| Key | Action |
| --- | --- |
| Enter | Start / Restart |
| A-Z | Type words |
| Backspace | Remove last letter |

## Streak and Speed

Every correct word increases your streak.....

A bigger streak also gives you more points......

After every 5 words.....
the game speed increases and new words start coming faster....

If you miss a word.... your streak goes back to 0.
